# Venezia CHS – Resident KYC (phone app)

Installable phone app (works on iPhone and Android) for the resident KYC of
Venezia Co-operative Housing Society Ltd, Tower B.

- This site holds **no member data**. Each form is sent straight to the Society's own
  Google Apps Script, which saves it in the Society's Google Drive.
- The form opens only with the personal link the Society sends to each flat.
